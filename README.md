# Boosteroid-AutoHotkey-script-
This script its useful for anyone that might want to play boosteroid whit less delay.

TUTORIAL
You open up boosteroid (the application not on browser) and start launch your steam game. after you open up the steam game start the script by just opening boosteroid.ahk ( the file i made you download).
after that you can tab out of boosteroid and go over to steam where you can stream your game from the boosteroid pc, this will grant you better quality and less delay. it also can be used to avoid inactivity.
You need to install AutoHotkey and than put this file in (if you are wondering how its simple so im not even gonna explain) and its gonna press ù every 3 minutes or so.
you can change the hotkey and time opening the file and changing the big number you see above that its the time and the hotkey where ù is mentioned.
if you close boosteroid app its gonna appear a message that says abort in that case just close it its in the hidden apps arrow thingy.
